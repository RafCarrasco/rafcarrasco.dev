## 6. Modal — bug + fix + lição

### Bug original (reportado por ti)
Modais de certificado/projeto abriam "dentro de uma seção" — backdrop não cobria viewport, conteúdo vazava por baixo. Desktop e mobile. X feio.

### Causa raiz REAL
`gsap.from(section, { y })` em `animations.ts` deixa `transform` (até identidade) em **toda `<section>`**. Ancestral com `transform` vira *containing block* de `position:fixed` — overlay resolve `inset:0` contra section, não viewport.

### Diagnóstico antigo estava errado
DEVELOPMENT.md seção 4.6 culpava o Lenis. Errado — Lenis default v1.3 usa scroll nativo, sem transform no body. `lenis.stop()` + `data-lenis-prevent` tratam scroll lock, não posicionamento. Corrigido na seção 4.11.

### Fix aplicado
- `modal.ts`: porta `.modal` pro `<body>` no init (escapa transform de ancestral)
- `animations.ts`: `clearProps:'transform'` no reveal das sections
- `modal.ts`: double-rAF na abertura, leak de listener corrigido
- `Modal.astro`: barra superior dedicada ao X (nunca sobre conteúdo — tua reclamação), SVG icon, scrollbar fina, full-screen mobile, padding via `--modal-pad`

### Lição transportável
Qualquer `transform` (mesmo identidade) num ancestral quebra `position:fixed` descendentes. GSAP `.from()` deixa transform residual — use `clearProps` ou portal pro body.

## 10. Notas técnicas / gotchas

### Cache do navegador no dev
HMR do Astro nem sempre aplica mudanças estruturais de `.astro`. Quando algo "não atualiza": **hard refresh (Ctrl+Shift+R / Cmd+Shift+R)** ou restart do dev server:
```bash
rm -rf node_modules/.vite .astro && npm run dev
```

### Porta 4321 presa
Vite escolhe próxima livre se 4321 ocupado. Pra forçar limpar:
```bash
# macOS
lsof -ti:4321 | xargs kill -9
```

### GitHub MCP
Token configurado bate com a conta RafCarrasco (confirmado: vê repos privados, criou repo + issues + PR com sucesso). No Mac: mesmo MCP funciona desde que esteja configurado no Claude Code do Mac.

### LF/CRLF
Git no Windows reclama de LF→CRLF nos commits. Inofensivo. No Mac não acontece.

### Lenis × position:fixed (NÃO é a causa)
DEVELOPMENT.md antigo (seção 4.6 + Lições) dizia que Lenis quebrava `position:fixed`. **Errado.** Lenis default não transforma body. Era GSAP. Mantive os fixes do Lenis (`lenis.stop()`, `data-lenis-prevent`) porque tratam scroll-lock (separado).
